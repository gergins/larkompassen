# Lärkompassen v1

Två elevportaler med egna länkar:

- Årskurs 1: https://gergins.github.io/larkompassen/ak1/
- Årskurs 5: https://gergins.github.io/larkompassen/ak5/

## Aktivera GitHub Pages (en gång)

Gå till **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → /(root) → Save**. Webbplatsen publiceras sedan på ovanstående länkar. Länkarna fungerar först efter att Pages aktiverats och publiceringen slutförts.

## Funktioner

- 15 ämnen per årskurs, med ett enkelt första avsnitt per ämne
- Förståelseförklaringar före interaktiva uppgifter
- Ledtråd, två försök och lösningsförklaring
- Resultat efter en genomförd omgång
- Aktuellt ISO-veckonummer och ett ämne som rekommenderas per vecka
- Svar lagras inte på servern, ingen inloggning

## Pedagogiska och tekniska begränsningar

Första versionen är en liten demonstrationsbank, inte fullständigt kursmaterial. Uppgifterna är framtagna för övning och inspirerade av Lgr22; veckorekommendationen är inte en officiell veckoplan från Skolverket eller barnens skola. Nya uppgifter skapas inte automatiskt varje vecka, utan det som växlar efter datum är ett ämnesförslag. Resultat sparas inte mellan besök. Alla ändringar i detta repository publiceras på samma Pages-URL när publicering är aktiverad.

Redigera `app.js` för att lägga till fler lektioner och uppgifter. Dela inte privata elevuppgifter i detta publika repository.
